# 벤처투자 소득공제 시뮬레이터 설계

## 목적과 범위
누구나 회원가입 없이 직장인 또는 개인사업자의 벤처투자 소득공제와 예상 절세 효과를 시각적으로 비교하는 한국어 반응형 웹사이트를 만든다. 개인정보와 입력값은 서버에 저장하지 않는다. 첫 버전은 단일 페이지이며 로그인, 결제, 투자상품 추천을 포함하지 않는다.

## 입력과 사용자 흐름
소득 유형, 계산 모드, 소득 금액, 기존 공제액, 투자 금액, 투자 방식, 투자 연도와 공제 적용 연도를 입력한다. 직장인의 간편 모드는 총급여에서 근로소득공제 및 명시된 기존 공제액을 반영한다. 개인사업자의 간편 모드는 매출이 아닌 필요경비를 차감한 사업소득을 받는다. 상세 모드는 투자 공제 전 과세표준과 공제 한도 산정에 필요한 종합소득금액을 별도로 받는다. 과세표준과 종합소득금액을 동일하게 취급하지 않는다.

## 결과와 화면
상단 소개, 입력 패널, 실시간 결과 카드, 투자금별 비교 그래프, 연도별 비교표, 계산 근거 설명 순서로 구성한다. 카드에는 공제 가능액, 적용 공제액, 공제 전후 산출세액, 지방소득세를 포함한 예상 세액 차이, 투자금에서 예상 절세액을 뺀 부담액을 표시한다. 부담액은 투자수익이나 원금보장을 뜻하지 않는다. 그래프와 동일한 수치 표를 제공한다.

## 계산 기준과 한계
세법 규칙은 연도와 투자 방식별 데이터로 분리한다. 공제 요건, 구간별 공제율, 종합소득금액 기준 한도, 적용 연도 선택 조건, 보유기간과 추징 조건, 소득세율을 공식 법령 및 국세청 자료에서 확인하고 출처 URL과 확인일을 기록한 규칙만 제공한다. 미확인 연도나 방식은 계산을 차단하고 지원 범위를 안내한다. 미래 연도는 확정 세법 또는 명시적 가정으로만 비교한다. 한 투자금의 공제를 여러 연도에 중복 적용하지 않는다.

예상 절세액은 공제 전후 산출세액 차이이며 실제 환급액과 구분한다. 세액공제, 다른 소득, 최저한세 등 미반영 항목은 결과 옆에 구체적으로 표시한다. 입력값은 유한한 0 이상의 수로 검증하고 불가능한 공제액 또는 과세표준 조합에는 설명을 제공한다.

## 기술 구성
브라우저에서 계산하는 TypeScript와 React 기반 정적 사이트로 구성한다. 계산 함수, 연도별 규칙, UI를 분리한다. 배포 서비스나 외부 계정 연결은 구현 및 검증 후 결정한다. 기존 굿노트 저장소는 변경하지 않고 /workspace/venture-tax에 작성한다.

## 검증과 완료 조건
공제 구간과 소득세율 경계값, 공제 한도, 0원 입력, 고액 입력, 공제 적용 연도, 직장인과 사업자의 계산 모드 차이를 단위 테스트로 확인한다. 공식 자료의 예시 또는 독립 수기 계산과 결과를 대조한다. 모바일과 데스크톱에서 입력 변경에 결과와 그래프가 함께 갱신되는지 검증하고 타입 검사 및 프로덕션 빌드를 통과해야 한다. 구현 완료와 외부 공개 배포 완료는 별도로 보고한다.
