## 남은 범위
일반 조합·펀드와 2026년 외 세법 기준 계산, 복합 소득, 다른 감면·세액공제·기납부세액, 정밀 지방세 특례 계산 미지원. 실제 환급액이나 최종 신고금액으로 사용하지 않는다.

## 작은 개선 사항
모드·계산 기준·그래프 버튼의 선택 상태에 aria-pressed 추가, 현재 투자금 그래프 표식을 샘플 점 대신 정확한 입력 위치에 표시하는 개선은 보류. 결과 카드와 계산 과정 수치는 실제 입력값으로 산출한다.

외부 공개 사이트에 배포하지 않았다. venturefit-site.zip은 dist/의 정적 파일 묶음이며, 배포 대상/계정 설정 후 공개 가능하다.

빌드된 dist/도 별도 정적 서버에서 실제 Chromium으로 확인했다. HTTP 200, 상세 입력(6000만 과세표준·8000만 소득·3000만 투자)의 예상 절세액 594만원으로 독립 수기 예시 일치, 페이지 오류 없음.
설치 스크립트와 start_skill 및 공식 조회용 도메인 4개(www.nts.go.kr, nts.go.kr, www.law.go.kr, law.go.kr)를 환경 설정 초안에 저장했다. 저장은 확인됐으며 환경 공개/새 머신 복원 검증은 수행하지 않았다.
